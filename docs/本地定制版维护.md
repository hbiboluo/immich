# 本地 Android 定制版维护

本仓库保留「仅上传新文件」备份方式及中文文案。为避免用户从官方更新入口换回缺少这些功能的版本，本地版永久关闭官方新版检测与更新提示。

## 更新策略

- 不订阅服务端的 `on_new_release` 官方发布通知，不处理官方最新版本。
- 不再比较 App 与服务端版本来提示安装官方 App，也不显示官方版本更新入口。
- 继续读取实际连接的服务端版本，供同步协议、通行密钥等功能兼容判断使用；登录时必要的协议兼容提示保留。
- 后续定制版从 Lab 应用市场手动下载更新。此变更不控制 Android 系统、第三方商店或用户手动安装行为。

仅隐藏提示仍会处理官方发布信息；增加可重新开启的设置也容易误恢复官方更新路径。因此本地分支直接移除官方发布事件处理与版本更新比较，无需用户额外配置。

## 本次版本

2026-11-17：`3.4.0-rc.0`，基础 build number `3040001`，ARM64 APK 的 versionCode 为 `3042001`。沿用已有自建版签名，可覆盖安装此前的同签名自建包；与官方签名版本不能互相覆盖。

## 验证与发布

回归验证覆盖新旧服务端版本均不触发官方更新提示、服务端版本和能力仍可读取，以及版本读取失败时保留已有能力信息。构建 ARM64 release 后核验包名、递增版本号、签名一致性、ZIP 完整性和原生库 16 KiB 对齐，再导入 Lab 应用市场并核对完整下载的 SHA256。
